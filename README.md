# 🚀 Astra & Codex Remote Sandbox
> Dedicated, isolated cloud execution environment for OpenAI Codex, gpt-6-astra, and ChatGPT Plus remote workspaces.

## Features
- **Zero Production Risk**: Safe isolated environment to test code, run terminal scripts, and explore architectures.
- **Full Node / TypeScript Support**: TypeScript 5+, Vitest, Biome/ESLint configured.
- **Python 3 Support**: Ready for Python execution and automation tasks.
- **Devcontainer Ready**: Instant startup in GitHub Codespaces and remote container environments.

## Quick Scripts
```bash
npm run dev      # Run main entrypoint
npm test         # Run test suites
python main.py   # Run Python runner
```
